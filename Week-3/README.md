# Week 3 — Python-Based Machine Learning Model Development and Evaluation Plan

## Project
**Customer Churn Prediction — Machine Learning Development Strategy**

## Objective
Design a complete, dataset-independent plan for developing, training, validating, evaluating, and potentially deploying a Python-based machine learning model.

## What was completed
- Defined a hypothetical customer churn prediction problem as a binary classification task
- Established project success criteria and a complete end-to-end ML workflow
- Planned data quality checks and preprocessing
- Covered missing-value handling, categorical encoding, scaling, feature engineering, and feature selection
- Defined train/validation/test separation and data-leakage prevention practices
- Compared candidate models: Logistic Regression, Decision Tree, Random Forest, and Gradient Boosting
- Planned baseline modeling, hyperparameter tuning, and cross-validation
- Defined evaluation metrics including Accuracy, Precision, Recall, F1-score, ROC-AUC, PR-AUC, Confusion Matrix, and calibration
- Covered model interpretability and error analysis
- Identified real-world challenges such as class imbalance, overfitting, data leakage, noisy data, concept drift, and model maintenance
- Added a conceptual deployment, monitoring, versioning, and retraining lifecycle
- Identified Python libraries and tools including Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, Plotly, Jupyter, Joblib, and Git/GitHub
- Planned a 33-hour Week 3 workload

## Scope
This is a **planning-stage task**. No dataset, code execution, or trained model results were required by the Week 3 assignment. The framework is designed to guide a future full Python implementation when a real dataset is available.

## Deliverable
The complete Week 3 DOCX report contains the detailed methodology, model comparison framework, evaluation strategy, workflow diagrams, deployment concept, challenges, tools, and 33-hour timeline.
