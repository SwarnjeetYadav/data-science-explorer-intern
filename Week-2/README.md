# Week 2 — Exploratory Data Analysis (EDA) & Visualization Framework

## Project
**Exploratory Data Analysis and Visualization Strategy**

## Objective
Design a comprehensive, dataset-agnostic framework for exploring and visualizing future datasets using Python.

## What was completed
- Defined the purpose and importance of Exploratory Data Analysis (EDA)
- Covered numerical, categorical, binary, datetime, text, and identifier data types
- Planned dataset profiling and data-quality checks
- Defined univariate, bivariate, and multivariate analysis techniques
- Designed strategies for handling missing values and outliers
- Defined visualization strategies for distributions, relationships, trends, and correlations
- Covered Histogram, Box Plot, Bar/Count Plot, Scatter Plot, Line Chart, Heatmap, Violin Plot, Pair Plot, and interactive Plotly visualizations
- Documented the roles of Pandas, NumPy, Matplotlib, Seaborn, Plotly, Jupyter, VS Code, and Git/GitHub
- Created a reporting and documentation framework for future EDA findings
- Planned a 33-hour Week 2 workload

## Important
This is a **planning-stage task**. No dataset was provided for Week 2, so no real dataset analysis or model training was required.
