# Week 1 — Data Science Project Planning and Strategy Design

## Project: Customer Churn Prediction & Retention Analytics

This folder contains the Week 1 planning deliverables for the Virtual Data Science Explorer Internship.

### What was completed
- Defined the hypothetical business problem and motivation
- Established project objectives and scope
- Designed the end-to-end data science methodology
- Planned data collection and data quality strategy
- Defined EDA and feature engineering approach
- Planned machine learning models and evaluation metrics
- Created a conceptual technical architecture
- Created a data science lifecycle flowchart
- Allocated a 33-hour Week 1 timeline
- Identified tools, expected outcomes, challenges, and mitigation strategies

### Important
This is a **planning-stage project**. No dataset is required for Week 1, so the repository does not contain model-training results yet.
